# Sales Search

Medical provider directory search tool with 50-state coverage, dynamic location loading, keyword boolean building, and category inclusion/exclusion inversion.

## Live Demo

[Launch Sales Search App](https://danielespinozetemp.github.io/Sales-Search/)

## Features

* **50 State & City Coverage:** Dynamic city dropdowns populated per US state via external data file.
* **Boolean Query Builder:** Generates precision search queries with specialty mappings and high-yield intent anchors.
* **Targeting Filters:** Toggle exclusions for job boards, directories, and social media platforms.
* **Invert Mode:** Converts negative filters to positive targeting arrays instantly.

## Usage

1. Select **Specialty**, **State**, and **City**.
2. Set claim type keywords or negative exclusion tokens.
3. Toggle category filter checkboxes as needed.
4. Click **Search** to execute query directly in Google search tab.
